HIYA DHOKAI — PERSONAL WEBSITE

Start locally: open index.html in a browser. Keep the folder structure intact.

Pages:
- index.html — Home
- lore/about.html — The Lore Behind the Girl
- sinceus/sinceus.html — SinceUs
- chapters/chapters.html — The Other Chapters (including TEDx)
- content/content.html — The Content Chapter

All photos are stored in each page's assets folder. The site uses Google Fonts, so an internet connection is needed for the selected web fonts.

To publish: create a GitHub repository, upload the contents of this folder to the repository root, then go to Settings → Pages → Deploy from a branch → main → /(root) → Save.
